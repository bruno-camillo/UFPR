# 🚦 Circuitos Digitais

Esta foi a minha primeira disciplina prática voltada a hardware na Engenharia de Computação. Aqui estão os projetos iniciais e fundamentais de modelagem de portas lógicas, circuitos combinacionais e máquinas de estado utilizando o simulador Logisim.

## 🛠️ Projetos Desenvolvidos
- `semaforo.circ`: Meu primeiro contato com Máquinas de Estados Finitos (FSM), controlando a lógica e o tempo de um semáforo de trânsito.
- `sequencia123.circ`: Circuito lógico com registradores para controle sequencial.
- `Trabalho circuitos`: Circuito consolidado para avaliação final da disciplina, unindo os conceitos básicos de portas lógicas.

## ▶️ Como Testar
Para simular o funcionamento:
1. Abra os arquivos `.circ` no software **Logisim**.
2. Utilize a ferramenta "Poke" (ícone de mão) para alterar os valores (0 ou 1) dos pinos de entrada e observar o comportamento lógico e o fluxo de energia pelos fios.
