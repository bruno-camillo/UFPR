# ⚙️ Projetos Digitais

Este diretório foca na integração e aplicação prática entre programação de baixíssimo nível e a resposta do hardware.

## 📁 Conteúdo
- **`trabalhoProjetos.circ`:** Projeto de circuito final desenvolvido para consolidar a lógica digital da disciplina.
- **`teste_risc-v.s`:** Código-fonte escrito em Assembly puro focado na arquitetura **RISC-V**, utilizado para validar as execuções do conjunto de instruções na arquitetura estudada.
