# 🧩 Primeiro Período - Fundamentos e Lógica

Primeiros passos no desenvolvimento de software, construindo uma base sólida de lógica de programação utilizando **Pascal**. 

O foco deste diretório é a manipulação de dados em memória (vetores e matrizes) e a resolução de quebra-cabeças lógicos através de código.

## 🚀 Destaques do Diretório (`Alg_1/`)

- **Jogos e Lógica Matemática:** 
  - Algoritmos para validar e resolver tabuleiros de `sudoku`.
  - Implementação de `quadrado_magico1` e `quadrado_magico2`.
  - Leitura de um jogo de `damas` e validação de `palavras_cruzadas`.
- **Manipulação de Matrizes:**
  - Resolução de `equacoes_lineares`.
  - Operações estruturais como `matriz_triangular` e `permutacao_matriz`.
- **Estruturas Lineares (Vetores):** 
  - Diversos exercícios focados em buscas, contagem de ocorrências, separação de números distintos e ordenação básica (`vetor02`, `vetor04`).
