# 🧮 Computação Científica, Paradigmas e Baixo Nível

Este período introduz a matemática aplicada a computadores (cálculos massivos), novos jeitos de pensar o código (Paradigmas) e o contato direto com a linguagem da máquina (Assembly).

## 🧮 Introdução à Computação Científica (ICC)
Estudo, compilação e teste prático de métodos numéricos em **C**. A maioria dos códigos deste diretório são algoritmos-base fornecidos pelo professor da disciplina para a compreensão prática de:
- Cálculo de zeros de funções e equações não-lineares.
- Resolução de matrizes inversas.
- Análise de algoritmos para Sistemas Lineares e Não-Lineares:
  - Eliminação de Gauss
  - Newton-Raphson para Sistemas
  - Método de Broyden

## 🧩 Paradigmas de Programação
Exploração de estilos além da programação imperativa clássica:
- **Haskell (Funcional):** Resolução de listas, recursão, currying, tratamento de dados e calculadoras sem manipulação de estado mutável.
- **Java (Orientação a Objetos):** Conceitos iniciais de OO (`BemVindo.java`, classes de `Entrada`).

## ⚙️ Software Básico
- Resolução de problemas acadêmicos através de instruções **Assembly** (`.asm`), otimizando ciclos e entendendo o funcionamento da CPU e de registradores.
