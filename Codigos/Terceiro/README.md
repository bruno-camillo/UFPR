# 🌳 Algoritmos 3 e Programação 2

Aprofundamento na linguagem C, estruturas de dados de alta performance, manipulação de arquivos e engenharia de software básica.

## 🧠 Algoritmos e Estruturas de Dados (`Alg3/`)
Implementação das principais estruturas de árvore e particionamento:
- **Árvores Binárias de Busca**
- **Árvores AVL** (balanceamento automático)
- **Heaps** e Filas de Prioridade otimizadas

## 🎮 Programação 2 e Desenvolvimento de Jogos (`prog2/`)
Aplicação prática dos conceitos de ponteiros, alocação dinâmica e gerenciamento de projetos através de `Makefiles`.
- **A1:** Criação e manutenção de um formato customizado de arquivos binários (Biblioteca GBV).
- **A3 (Projeto de Jogo 2D):** 
  - Engine simples em C processando leitura de cenários via `mapa.txt`.
  - Manipulação de `sprites` (jogador, inimigos laranjas e roxos, portas, pedras).
  - Controle e validação de colisões e estados de inimigos.
