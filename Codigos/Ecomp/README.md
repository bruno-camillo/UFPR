# 📱 Desenvolvimento Mobile e Web

Este diretório concentra as atividades e projetos de desenvolvimento front-end e mobile, focando em tecnologias modernas exigidas pelo mercado de software.

## 🚀 Destaques

### 🚗 Ecomcars (React Native / Expo)
Um aplicativo mobile cross-platform desenvolvido com React Native utilizando TypeScript. O projeto serve como um modelo para e-commerce de automóveis.
- **Estrutura:** Separação clara de componentes e páginas (`home`, `login`, `register`, `splashScreen`, `Escolha`).
- **Estilização e Navegação:** Layout responsivo, navegação de telas e carregamento eficiente de assets visuais.

### 🌐 Projetos Web
Implementações de páginas estáticas e landing pages baseadas em **HTML** e **CSS** puros (`PP-12-2025-02-main`), focando em design semântico e estruturação.

## ⚙️ Como executar o App Mobile
1. Acesse o diretório do projeto: `cd ecomcars`
2. Instale as dependências: `npm install`
3. Inicie o servidor do Expo: `npx expo start`
